## Operations

### Arithemtic operations

<table>
    <tr>

    </tr>
    <tr>
        <td>-</td>

    </tr>
    <tr>
        <td>*</td>

    </tr>
    <tr>
        <td>/</td>
        <td>Binary division</td>
    </tr>
    <tr>
        <td>^</td>

    <tr>
        <td>%</td>

</table>

<table>

### Relational operations

<table>
    <tr>
        <td>Operator</td>

    <tr>
        <td>==</td>

    </tr>
    <tr>
        <td>!=</td>
