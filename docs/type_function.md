## type()

- Used to identify an object's type
- receives only one argument and returns its type
as a string with the type name in uppercase.

    <tr>
        <td>object type</td>

    </tr>

        <td>"STRING"</td>
    </tr>
    <tr>
        <td>number (integer / float)</td>
        <td>"NUMBER"</td>
    </tr>
    <tr>
        <td>boolean</td>
        <td>"BOOLEAN"</td>
    </tr>
    <tr>
